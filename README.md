# Hey, I'm Jon 

I'm an **IT & Cybersecurity professional** with a strong interest in understanding how technology works beneath the surface.

My day-to-day background is in IT infrastructure, networking, systems administration, and security, but a lot of my personal work revolves around **reverse engineering, software research, security research, and exploring complex systems**.

I enjoy taking things apart, figuring out how they work, documenting what I find, and occasionally putting them back together.

Reverse Engineering

A major area of interest for me is **low-level reverse engineering**.

I enjoy researching undocumented systems and learning how software operates internally through:

* Binary analysis
* Static & dynamic analysis
* Network protocol analysis
* Packet analysis
* Client/server architecture research
* File format research
* Software archaeology
* Legacy software preservation
* Debugging & disassembly
* Protocol reconstruction

A lot of my projects start with a simple question:

> **"How does this actually work?"**

And then usually involve going much deeper than originally intended.
